
# Lossless Text Compressor & Decompressor
# Программа для сжатия и распаковки текста без потери данных

## 1. Описание проекта

Данный проект представляет собой программу для сжатия и распаковки текстовых данных, написанную на языке Java.

Программа использует метод сжатия RLE (Run-Length Encoding), который позволяет уменьшить размер текста за счёт подсчёта подряд идущих одинаковых символов.

Сжатие является обратимым: исходный текст можно полностью восстановить без потери информации.

## 2. Основные возможности

- Сжатие текстовых данных.
- Распаковка сжатого текста.
- Обработка цифр и специальных символов.
- Поддержка многозначных чисел.
- Подсчёт статистики сжатия.
- Вычисление количества и процента сэкономленных символов.
- Обнаружение повреждённых или некорректных данных.
- Чтение и запись текстовых файлов.

## 4. Принцип работы программы

Для сжатия используется алгоритм RLE (Run-Length Encoding).

Алгоритм подсчитывает количество одинаковых символов, идущих подряд, и заменяет их числом и самим символом.

Пример:

Исходный текст:
AAAAABBBCCDAA

Сжатый текст:
5A3B2C1D2A

При распаковке программа восстанавливает исходный текст.

Цифры и обратный слеш дополнительно экранируются, чтобы избежать ошибок при распаковке.

## 6. Запуск программы

1. Открыть проект в IntelliJ IDEA.
2. Открыть файл Main.java.
3. Запустить программу.
4. Выбрать необходимый режим.

Режим 1 — сжатие текста.

Режим 2 — распаковка текста.

Исходный текст для сжатия находится в папке input.

Результаты работы программы сохраняются в папке output.

## 7. Тестирование

Для проверки правильности работы программы создано 10 автоматических тестов.

Тесты проверяют:
- Повторяющиеся символы.
- Одиночные символы.
- Большое количество повторений.
- Многозначные числа.
- Цифры.
- Специальные символы.
- Различные комбинации символов.

Результаты тестирования:

- Успешно пройдено: 10.
- Не пройдено: 0.

Для запуска тестов необходимо открыть TestRunner.java и выполнить его.
